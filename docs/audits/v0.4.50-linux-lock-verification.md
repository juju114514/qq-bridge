## 三、这证明了什么 / 没证明什么

**证明**：

- 端口互斥在 **Linux 内核**上成立（`EADDRINUSE` 语义与 Windows 一致）
- 进程被 `SIGKILL` 后端口**立即释放** → 崩溃自动恢复不依赖任何文件状态
- 18 条用例（含 4 条 timeout 注入）在 Node 22 上全过

**没证明**：

- 跨网络命名空间（Docker bridge / 两台机器）仍不互斥 —— 这本来就是设计边界，见 `docs/guides/DOCKER.md`
- 沙箱环境是单 netns，等价于"同机多进程"场景，不覆盖容器边界

## 四、顺带发现：打包用了反斜杠
