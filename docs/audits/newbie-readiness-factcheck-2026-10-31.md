# 「新手友好度 6/10」这份评估的事实核对（2026-10-31）

> 有人拿了一份外部评估，说本仓库「没有一键安装脚本、没有批处理启动、没有自检向导、
> 缺人格导入」。下面是逐条核对结果 —— **四条里三条是错的**（评估方大概没看仓库根目录）。

## 一、逐条核对

| 外部说法 | 事实 | 证据 |
| --- | --- | --- |
| ❌「没有一键安装脚本」 | **有** | `scripts/first-run.ps1`：体检 → 装依赖 → 生成 `config.json` → 问要不要启动 |
| ❌「没有 Windows 批处理一键启动包」 | **有** | 根目录 `start.bat`（带守护：挂了 5 秒重启 + `state/` ACL 加固）、`restart.bat`（按锁文件 PID 杀旧实例，避免双开） |
| ❌「缺少大肥鱼人格一键导入」 | **不需要导入** | `roles/` 里已内置 4 张卡（小鲸鱼/傲娇助手/樱羽艾玛/派蒙），控制台「人格」页一键切换（`POST /api/role`）。人格是本地文件，没有"导入"这道工序 |
| ⚠️「没有自检向导」 | **有基础、缺双击入口** | `scripts/preflight.mjs`（16 项：Node/依赖/config/state 可写/端口/DSH/SnowLuma/人格卡）+ `/自检` 聊天指令。**本轮补了 `自检.bat`**（双击跑，末尾 pause 不闪退） |
| ⚠️「NapCat 没有新手引导」 | **有，但埋在 QUICKSTART 里** | `QUICKSTART.md` 的「用 NapCat 替代 SnowLuma（实测通过）」一节，含 4 个必踩的坑 |

## 二、这一轮真正补的东西

1. **`自检.bat`**（新增）—— 双击就能跑的向导，末尾 `pause`，新手不会看到窗口一闪而过。
2. **`docs/guides/BEGINNER.md`**（新增，223 行）—— 零基础八步，每步「做什么 / 应该看到什么 / 没看到怎么办」+ 卡点速查表 + 术语小抄。
3. BEGINNER 里改成**双击 `start.bat` / `restart.bat`** 的真实路径（原来只写了 PowerShell 命令）。

## 三、还剩的真实缺口（承认）

| 缺口 | 说明 | 难度 |
| --- | --- | --- |
| SnowLuma / DSH 的**安装**仍要手动 | 两个都是第三方程序，且都要**扫码登录/图形安装**，脚本代劳不了（也不该代劳） | 无法自动化，只能写清楚 |
| 自检没有**图形向导** | 现在是终端输出；做成控制台里的分步向导是可行的（P2） | 中 |
| 一键"从零到能回话" | 需要一个安装器把 Node/依赖/config/NapCat 全包了；涉及下载第三方二进制，风险与体积都大 | 高，暂不做 |

## 四、结论

「没有批处理启动」「没有一键安装」「没人格导入」这三条**与仓库现状不符**；
真正的短板是**第三方程序的安装与扫码**——这部分不是脚本能解决的，只能把每一步写得更清楚。
本轮的 `BEGINNER.md` + `自检.bat` 就是朝这个方向做的。
