## 这一版最想说的：坏了要看得见

0.5.42 修的四个问题，**共同点是一个报错都没有**：

| 症状 | 真相 |
| --- | --- |
| 网关死了 40 分钟没人知道 | 进程没了，但界面上什么都看不出来 |
| 扫码确认了，控制台没反应 | 轮询结果被浏览器缓存，永远返回第一次的 `801` |
| 明明登录成功，界面显示"二维码过期" | 成功后轮询没停，`800` 把状态盖掉了 |
| 10-29 写的记忆，11-02 变成了空 | 被一次旧快照整体落盘覆盖，日志里连 `clear` 都没有 |

所以这版的重点不是加功能，是**让这些静默失败有痕迹**。

## 新增

### 顶栏三颗胶囊

```
● DSH 已连接    ● 网关正常    ● 官方通道正常
```

每 30 秒刷新，点一下跳到对应页面。**判据按通道分开给**：

- 官方通道：WS 连着 + 已就绪 + `> 5 分钟没数据` → 判"假连接"
- 网关：端口在听 + WS 已连 + OneBot `online:true` → 三条硬信号
  （网关**不能**用"多久没数据"判 —— 凌晨三小时没人说话是安静，不是故障）

三档状态：`正常` / `重连中` / `未运行`；连「进程活着但 QQ 掉登录」也看得出来。

### 网关一键启停

控制台「调试与运维 → 个人号网关」多了「启动网关」和「停止（清理重复进程）」。

修掉的坑：

- **SnowLuma 不做单例** —— 端口被占也照起、旧的不退出。实测堆到 **8 套 / 16 个 node.exe / 约 1 GB 内存**
  （启动时间从 12:56 到 14:12，每点一次多一套）。现在启动前先清残留，识别按命令行**或**可执行路径。
- **拉起来几秒后自杀** —— `stdio: 'ignore'` 让子进程拿到一个不可用的 stdout 句柄，SnowLuma 初始化完就静默退出。
  改成重定向到 `logs/gateway.log` 后连续 90 秒稳定。

### 音乐账号：扫码登录 + 状态检测

点歌页新增「音乐账号」区块，网易云 / QQ 音乐各自显示状态、可扫码登录/退出，登录后显示**昵称与会员等级**。

登录后 cookie 写进 `netmusic-cookie.txt`，点歌能拿 VIP 高音质（黑胶实测可用）。

踩到并写进 CHANGELOG 的坑：

| 现象 | 原因 |
| --- | --- |
| 扫码确认后一直 `8821` | 风控行为验证；出口在境外（含代理/VPN）必现 |
| `803` 成功但 cookie 是空的 | 凭据只在 `Set-Cookie` 头里，`body.cookie` 可能为空 |
| 一直显示"等待扫码" | 轮询响应可被缓存，永远拿到第一次结果 |
| 发短信提示"网络环境存在安全风险" | 同上，出口 IP 被判定异常 |

所以给了三条路：**扫码 / 手机号+密码 / 直接粘贴 cookie**。控制台会显示当前出口国家，境外时直接告诉你会出什么问题。

### 上下文用量面板

环形看余量 + 分段条看构成：系统提示词 / 工具定义 / 对话消息 / 未分类。

数据来自 DSH 会话快照里的 `contextPressure` 与 `contextBreakdown`，**不做估算**：

- 容量未知 → 显示绝对值，不编百分比
- 还没收到快照 → 显示"还没收到"，不填 0
- 压力超过容量 → 封顶 100%，不出 137%

### 记忆护栏

落盘前比一次磁盘：如果内存里 `memberImpressions` / `activeTopics` / `pendingThoughts` 是空的、
而磁盘上明明有内容，就把磁盘那份救回来并记日志：

```
[memory] 阻止覆盖：group:100000001 的 memberImpressions 磁盘上有 2 条，内存里是空的，已保留磁盘版本
```

范围克制：只保护这三个记忆字段（水位/时间/消息缓存随时可能合法变空），
会话被整体删除也不拦（那是重置，不是覆盖）。

星图顺带修了：以前对没有记忆的会话直接跳过，现在照样画出来并点名。

## 已知限制

- 音乐**播放地址**需要登录态（QQ 音乐几乎全曲库、网易云 VIP 曲目）；未登录时点歌只能拿普通音质
- 扫码受**出口 IP** 影响：境外出口会触发风控，界面会明确提示，用密码或粘贴 cookie 可绕过
- QQ 音乐的下载链路未在登录态下验证过（搜索、取源参数、错误分支都验证了）
