## v0.4.4 · 插件自包含，可以直接从仓库装

> 小更新。让"填个地址就能装"成立。

### 三个改动

| 改动 | 为什么 |
| --- | --- |
| `plugin/vendor/` 打进依赖模块（onebot-ws + 通道闸） | 之前用 `../src/...`，单独安装后找不到 —— 装得上、跑不起来 |
| DSH 相关 peer 标 `optional` | 它们不在公共 npm 上；不标的话从 git 安装会去 npm 拉，直接失败 |
| 移除仓库根 `postinstall` | pnpm 因此报 `ERR_PNPM_IGNORED_BUILDS`，**git 方式安装被拦** |

### 三种安装方式

| 方式 | 填什么 |
| --- | --- |
| 本地路径（推荐） | `<你的仓库>\plugin` |
| GitHub 子目录 | `github:juju114514/qq-bridge#main&path:/plugin` |
| npm 包名 | ❌ 404（插件是 `private`，未发布） |

> ⚠️ 直接填仓库根地址不行（根目录是桥接应用，不是插件）。

### 守卫

`scripts/check-plugin-vendor-fresh.mjs`：vendor 副本必须与 `src/` **逐字节一致**，
并检查插件里没有跨包相对导入。

详见 [PLUGIN-MODE.md](https://github.com/juju114514/qq-bridge/blob/main/docs/guides/PLUGIN-MODE.md)。
