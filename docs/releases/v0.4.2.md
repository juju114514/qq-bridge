## v0.4.2 · 升级指南（给还在用 0.2.x / 0.3.x 的人）

> 纯文档版本，没有代码改动。

新增 [docs/guides/UPGRADE-FROM-OLD.md](https://github.com/juju114514/qq-bridge/blob/main/docs/guides/UPGRADE-FROM-OLD.md)：

- **30 秒版**：备份 `config.json` + `state/` → 拉代码 → `npm install` → `restart.bat` → `自检.bat`
- **配置项对照表**：0.3.1 的 `notifyAgentErrors` / `roleInjectEvery`、0.4.1 的 `channel.enabled`
  —— 全都标了"默认值等于旧行为，一个都不改也能跑"
- **行为变化**：角色卡改 `isOwner`、`consolePort` 启动校验、`/api/voice/send` 修复、通道认领
- **从 0.2.x 上来要额外做的**：Node ≥22.13、DSH ≥0.2.1-rc.2、preset 名 `qq-chat-v2`、跑一次 `setup-dsh.mjs`
- **state 兼容性**：只增不改；新增 `state/memory/`、`channel-mode.json`、`plugin-events.jsonl`
- **回滚方法**：换回旧代码 + `state.bak-*` 覆盖
- **升级后自查清单** 5 条

### 一句话

**0.4.x 没有破坏性变更**，老配置直接能用；新功能（角色卡节奏注入、插件模式）都是可选的。
