## v0.4.17 · 工具只回「最近 N 条」，正文丢了

### 现象

```
qqb_get_recent_messages(group:994920175) → "最近 9 条"
qqb_get_unread_messages(...)             → "9 条未读"
```

有计数、**没正文**，工具对模型等于没用。

### 根因

`OUTPUT.render` 只渲染 `v.message`，把 `messages` 数组整个丢掉：

```js
const text = v.message;            // "最近 9 条"
return [{ type: 'text', text }];   // ← 数据没了
```

execute 返回的对象是完整的，问题只出在 render（决定模型看到什么）。

### 修后

```
最近 2 条
  #1 1599683156: 在吗？
  #2 我: 在的，我在。
```

顺带补上 `handoff`（交接记忆）、`role`（角色卡）、`wake`（唤醒配置）、
`readThroughSeq`、`timeout`。

### 教训

工具要测 **render 的产物**，不是只测 `execute()` 的返回值。
