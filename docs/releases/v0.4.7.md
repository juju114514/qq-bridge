## v0.4.7 · 插件工具改名 `qqb_*`，彻底避开 MCP 同名

### 之前为什么没修好

0.4.5 的「同名就跳过」依赖 `ctx.tools.get(name)` 能看见 MCP 注册的工具。
**真机上它看不见**（MCP 工具在另一层），于是插件照样注册了 `qq_get_prompt`，
冲突依旧 → 供应商侧 schema 仍是 `type: null`，每轮报错。

### 现在

插件工具统一加前缀：

| 旧名 | 新名 |
| --- | --- |
| `qq_ping` | `qqb_ping` |
| `qq_send_message` | `qqb_send_message` |
| `qq_reply` | `qqb_reply` |
| `qq_get_prompt` | `qqb_get_prompt` |
| `qq_mark_read` | `qqb_mark_read` |
| `qq_get_recent_messages` | `qqb_get_recent_messages` |
| `qq_get_unread_messages` | `qqb_get_unread_messages` |
| `qq_wait_for_messages` | `qqb_wait_for_messages` |

- MCP 的 `qq_*` 一个没动，两边并存
- 参数、返回、降级语义全不变，只是名字变了
