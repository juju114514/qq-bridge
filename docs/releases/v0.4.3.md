## v0.4.3 · 插件模式真机跑通（三个必需项）

> 小更新，修的是"插件装上了但连不上 QQ"这类只在真机上出现的问题。

| 问题 | 现象 | 修法 |
| --- | --- | --- |
| `inject` 少了 `agents` | `cannot get property "agents" without inject`，通道启动直接失败 | `inject = ['tools', 'agents']` |
| 挂载时探 sidecar 只给 1.5s | 宿主启动忙 → 明明开着却报「sidecar 未连接」 | 超时 5s，并把失败原因写进日志 |
| 认领文件用相对路径 | `stateDir` 默认 `./state`，cwd 不是 sidecar 的 state → **通道互斥形同虚设** | 新增 `stateDir`，文档要求与 sidecar 一致 |

### 真机验证（隔离 DSH_HOME，未影响桌面版）

```
[qq-plugin] 通道模式：plugin（free）
[qq-plugin] OneBot 已连接：ws://127.0.0.1:3001
[qq-plugin] QQ 通道已启动
[qq-plugin] 已挂载；sidecar 在线（mode=bridge）
```

`state/channel-mode.json` → `mode: plugin`，sidecar 处于 sidecar-only。

### 文档

[PLUGIN-MODE.md](https://github.com/juju114514/qq-bridge/blob/main/docs/guides/PLUGIN-MODE.md) 新增「三个真机才会暴露的必需项」：
`accessToken` 要用 **WS** token、`stateDir` 必须与 sidecar 一致、`inject` 要含 `agents`；
以及「杀进程后 60 秒内重启会被心跳 TTL 拒绝，删 `channel-mode.json` 即可」。
