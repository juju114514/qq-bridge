## v0.4.11 · sidecar-only 时**真的**不连网关

### 现象

```
[bridge] sidecar-only 模式（channel.enabled=false）：不连接 QQ 网关，也不占用通道认领
[bridge] SnowLuma 已连接：ws://127.0.0.1:3001      ← 说好的不连呢
```

`Get-NetTCPConnection -RemotePort 3001` 出现**两条**：DSH 插件一条 + bridge 一条 →
同一条群消息被消费两次，可能各回一句。

### 修法（两层兜底）

```js
if (!channelModeClaimed) {
  bot.reconnect = false;
  bot.connect = async () => {};   // 真机第二次踩到：close() 之后仍有连接建立
  bot.close(1000, 'sidecar-only');
}
```

自愈路径里的重连也受 `bot.reconnect !== false` 约束。

### 验证

```
3001 连接: DeepSeek Harness.exe(12708)   ← 只剩插件
[bridge] 已断开 SnowLuma 连接并禁用重连（本实例只作 sidecar）
```
