### 守卫 `check-lock.mjs`（已挂进审计）

上锁期查 5 条（状态行 / 示例配置 / README 横幅 / 审计记录 / 免责声明在位），
解锁后反向查 2 条（横幅必须清掉，防止"说解锁了但没清"）。

两个方向都实测有效：故意改成「已解锁」却不清横幅 → **守卫报红**。

### 明确不做

- 不拆仓库（官方通道只有 ~30KB，拆开收益低于成本）
- 不加运行期开关（不会因为锁让本地失效）
- 不删代码（随时可解）
