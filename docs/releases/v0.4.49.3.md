## v0.4.49.3 · 官方通道实例锁改用 OS 端口互斥 + 修红了的 audit CI

> 承接三轮独立复核。**锁的实现整体换掉**：文件协议（含 `.guard` sidecar）做不出严格互斥。

### 为什么换

三轮复核结论一致：任何「读-判断-删」文件锁都有 TOCTOU；而且 Node 在 Windows 上以共享模式打开文件
（`FILE_SHARE_READ|WRITE|DELETE`），连"句柄还在所以不能 rename"这个证明也不成立（实测 rename 成功）。

### 现在：回环端口绑定

| 特性 | 说明 |
| --- | --- |
| 互斥 | 同一端口只能被一个进程 listen，**内核保证**，没有协议层竞态 |
| 崩溃恢复 | 进程死 → 内核释放端口 → 下一实例直接拿到，**无需人工删锁** |
| 状态文件 | 只做诊断（pid/token/beatAt/port），删了不影响互斥 |
| 端口 | `QQB_LOCK_PORT` 优先，否则 `31200 + sha256(instanceId) % 2000` |
| 错误分类 | `held` / `permission` / `unavailable` / `timeout` / `error`；非法显式端口直接 `invalid-port`，不回退 |
