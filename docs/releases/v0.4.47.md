## v0.4.47 · 第二次弹窗根因：watchdog 任务漏了 `-WindowStyle Hidden`

> 0.4.43 修好主任务后，窗口**仍然**每隔几分钟弹一次。这次找到真凶。

### 两个根因，两条任务

| 任务 | 触发 | 症状 | 修于 |
| --- | --- | --- | --- |
| `qq-bridge` | `RestartOnFailure=PT1M×999` | **1 分钟**一次，重打完整启动日志 | 0.4.43 |
| **`qq-bridge-watchdog`** | `PT5M` 重复触发 | **隔几分钟**弹一次 | **0.4.47** |

watchdog 的动作参数一直是：

```
-NoProfile -ExecutionPolicy Bypass -File "…\keepalive.ps1"     ← 缺 -WindowStyle Hidden
```

它每 5 分钟起一个**可见** PowerShell 跑 keepalive —— 这就是"一直在弹"。

### 改了什么

- 新增 `scripts/harden-watchdog-task.ps1`（管理员；只改参数，触发器/设置保持原样，先备份）
- **已提权执行**：watchdog 现在带 `-WindowStyle Hidden`
- `verify-qq-bridge.ps1` 新增 3 条：watchdog 带 Hidden / 无 RestartOnFailure / 仍每 5 分钟
- 手动触发验证：进程起来后 **`MainWindowHandle = 0`**（无窗口），健康时秒退

### 真机结果

```
verify-qq-bridge.ps1 → 19 项通过 / 0 失败
/health/detail → version=0.4.46  epoch=12  ready=true
```

> `/health` 显示 0.4.46 是因为该进程在 0.4.47 之前启动；下次重启即为 0.4.47，指纹机制本身正常。
