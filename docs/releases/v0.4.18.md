## v0.4.18 · 插件模式没有人设（角色卡没挂上）

### 现象

插件模式下它回话像通用助手，还带 Markdown 表格 —— **没有人设卡，也没有 QQ 场景规则**。

### 根因

桥接模式的人设来自 DSH 的 **agent preset**（`qq-chat-v2`：persona + 场景规则 + 工具面）。
插件建 agent 时只给了 `sessionId / meta.cwd / 模型`，**漏了 `agentPreset`**：

```js
meta: { chatKey, cwd }          // ← 少了 agentPreset
```

拿到的是 DSH 默认系统提示，与 QQ 聊天无关。

### 修法

```js
meta: { ..., agentPreset: config.agentPreset }   // 默认 'qq-chat-v2'
```

新增配置项 `agentPreset`（可换 `qq-chat` 或自定义）。建好后日志会打印实际生效值：

```
agent 已建：preset=qq-chat-v2 cwd=…\state\agents\group_994920175
```

### 顺带

`mdToPlain` 把表格分隔符 `|` 换成 `·`：QQ 里 `a | b | c` 很难读。
