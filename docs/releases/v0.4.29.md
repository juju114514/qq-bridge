## v0.4.29 · 修 Official 通道的三个缺口

对应 [审计文档](https://github.com/juju114514/qq-bridge/blob/main/docs/audits/official-channel-audit-2026-10-31.md) 的缺口 1/2/3。

### 缺口 2（先修）：管理员在官方通道不再"永远不是 owner"

- 新增 `official.ownerOpenid`（**openid，不是 QQ 号**）
- owner 判定同时支持两种身份：
  - 个人号：`event.user_id === cfg.ownerQQ`
  - 官方通道：`official-<openid>` 去前缀后比对 `official.ownerOpenid`
- 顺带修掉 `&&` 链返回 `''` 导致 `isOwner` 不是布尔值的隐患

### 缺口 1：官方通道有正确的自我身份

- `selfIdentityTextV2(isOfficial)`：官方通道用 `official.botName`，**不再借用 SnowLuma 的个人号**
- 启动后打日志：`[official] 自我身份已设置：显示名「…」（官方通道无 QQ 号）`
- prompt 的 @ 提示按通道区分（官方写 `@你`，个人号写 QQ 号）

### 缺口 3：官方入站按 `message_id` 去重

官方重连会重投同一 `msg_id`，入站没有 seq 可用。新增 10 分钟 TTL 的有界去重表，
命中时打 `[official] 重复消息，跳过`。

### 测试

`test-incoming-guards.mjs` 新增两条 owner 用例，审计 128/128。

### 还需要你做的

```jsonc
// config.json
{ "official": { "ownerOpenid": "<你的 openid>", "botName": "小鲸鱼（官方）" } }
```

openid 从日志 `[official] 进入处理：… openid=xxxxxx…` 里拿。
