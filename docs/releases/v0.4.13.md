## v0.4.13 · 两条路都开放，一键切换

桥接模式和插件模式**并存**，用户按需选，不用再手改两个文件。

```powershell
node scripts/switch-mode.mjs status   # 看现在谁在收
node scripts/switch-mode.mjs bridge   # 路线 A：常驻 bridge
node scripts/switch-mode.mjs plugin   # 路线 B：DSH 插件
```

Windows 上也可以双击：`切换-桥接模式.bat` / `切换-插件模式.bat`

| | 路线 A：bridge | 路线 B：插件 |
| --- | --- | --- |
| 谁收 QQ | `src/bridge.js` 常驻进程 | DSH 内的 `qq-bridge` 插件 |
| 控制台/记忆/工具 | bridge 自己 | bridge 以 sidecar-only 跑 |
| 适合 | 长期 24/7 挂机 | 已在用 DSH、想让 QQ 成为入口 |

脚本会改 `config.json` 的 `channel.enabled` 与 profile 的 `enabled`，并打印**正确的重启顺序**：

- 切到 A：先重启 DSH（插件释放通道）→ 再重启 bridge
- 切到 B：先重启 bridge（让出通道）→ 再重启 DSH
