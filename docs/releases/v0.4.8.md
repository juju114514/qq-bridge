## v0.4.8 · `sync-snowluma-token.mjs`

SnowLuma 的 **HTTP token 与 WS token 是两个不同的值**，重新扫码后都会变。手改很容易搞反。

| 位置 | 字段 | 用哪个 token |
| --- | --- | --- |
| `config.json` | `snowluma.accessToken` | **HTTP**（桥接 API 调用） |
| DSH profile 的 `cordis.patch.yml`（`qq-bridge`） | `accessToken` | **WS**（插件连 3001） |

```powershell
node scripts/sync-snowluma-token.mjs --dry   # 先看会改什么（默认打码）
node scripts/sync-snowluma-token.mjs         # 真改
```

- 从 SnowLuma 的 `config/onebot_<QQ>.json` 读两个 token
- 多账号用 `config.json` 的 `selfQQ` 固定；没配会告警并取第一个
- 只在必要时写文件；改完提示重启 DSH
