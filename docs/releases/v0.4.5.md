## v0.4.5 · 修同名工具冲突（插件 + MCP 同时挂时整轮失败）

### 现象

```
本轮运行失败 Invalid schema for function 'qq_get_prompt':
schema must be a JSON Schema of type: 'object', got 'type: null'
```

### 原因

桌面版同时还挂着 `mcp-snowluma`，它也有 `qq_get_prompt` 等工具。
**同名工具并存**时，供应商侧拿到的函数 schema 变成 `type: null`，整轮直接失败。

（我们自己的 schema 是合法的：用宿主同版本 `dsh-tools` 编译出来是 `type: 'object'`。）

### 修法

注册前先查 `ctx.tools.get(name)`：

- 已存在 → **跳过**并记一行日志（该功能走 MCP 那份）
- 不存在 → 正常注册

冲突时插件仍提供**不撞名**的工具（`qq_ping`、`qq_send_message` 等除 `qq_get_prompt` 外的部分会按撞名情况跳过）。

### 谁会遇到

只有"插件 + MCP 同时挂"的环境（桌面版就是这样）。纯净插件环境不会触发。
