## v0.4.50 · 控制台新增「记忆星图」

把长期记忆（`longTermMemories`）画成星图：**一个会话 = 一团星，一条记忆 = 一个星点**。

### 视觉语义（对齐遗忘曲线）

| 元素 | 含义 |
| --- | --- |
| 星点大小 | 有效权重 `weight × 0.5^(天数/30)`，log 尺度 |
| 星点颜色 | 新鲜 = 暖金，陈旧 = 冷蓝紫 |
| 连线 | 原子↔会话；原子↔原子（共享 ≥2 tag，或 1 个 tag 且双方权重高） |
| 亮度 | 最近被命中 |

### 交互

- 悬停摘要 / 点击详情（权重、命中次数、时间、标签、来源）
- 拖节点、拖空白平移、滚轮缩放
- 底部会话 chip：一键居中放大
- 最低权重滑杆过滤

### 实现

零后端改动，复用 `/api/socialV2/states` 与 `/api/socialV2/memory?key=`；
纯 canvas 力导向，无第三方图表库；本地审计 144/144。
