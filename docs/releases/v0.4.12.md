## v0.4.12 · 插件里 @ 判定失效（事件没有 `self_id`）

> hotfix（直接提在 main）：真机第一次端到端发消息就踩到了。

### 现象

群里 `@小鲸鱼 在吗` → **完全没反应**，不报错、事件流也没记录。
但通道确实被插件认领（`channel-mode.json` = plugin），3001 上只有插件一条连接。

### 原因

SnowLuma 推送的事件里**没有 `self_id`**，而插件这样判定：

```js
gate(event, { selfId: event?.self_id });        // undefined
const target = String(selfId ?? event?.self_id ?? '');  // ''
if (!target) return false;                       // 永远"没 @ 我"
```

`requireMention: true` 下每条群消息都被判成 `no-mention` 丢掉。
桥接没这问题——它启动时用 `get_login_info` 拿到了自己的 QQ。

### 修法

```js
const info = await channel.call('get_login_info', {});
state.selfId = String(info?.data?.user_id ?? '');
gate(event, { selfId: state.selfId ?? event?.self_id });
```

取不到会打警告，不再静默失败。
