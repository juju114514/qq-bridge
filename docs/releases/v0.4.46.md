### 移植的（他们有，我们缺）

`src/dsh-port.js` 新增 `dshUrlFromEnv()`：**优先用 `DSH_WEB_URL`**（DSH 注入给子进程的精确地址），
比"按进程名扫监听端口"更准。

```
发现顺序：DSH_WEB_URL → 已配置端口 → 系统报的 DSH 端口 → 常见默认
```

只接受本地回环 http(s)，拒绝外部地址。
