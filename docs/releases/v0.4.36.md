## v0.4.36 · 运行时指纹（version / commit / presetHash）

对应外部评审第 2 条：「运行时到底执行什么」。
一天 32 个版本 + 三份 preset 副本，出问题时**没法从日志判断跑的是哪套代码**。

### 现在能查了

```json
GET /health
{
  "ok": true, "mode": "bridge", "version": "0.4.36",
  "commit": "929f29a7de1a",
  "preset": "qq-chat-v2",
  "presetHash": "bc836a15c8c9",
  "presetSource": "dsh/agent-presets/qq-chat-v2/qq-tool-restrict.mjs"
}
```

启动横幅：

```
运行时指纹：version=0.4.36 commit=929f29a7de1a preset=qq-chat-v2@bc836a15c8c9
```

### 实现

- `src/build-info.js`：读 `.git/HEAD`（**不打子进程**，秒级）+ 算 preset 的 sha256
- 放在 `src/` 而不是 `src/core/`：core 有「禁止 IO import」的纯度守卫
- `scripts/test-build-info.mjs`：5 条，含「仓库没有 `.git` 时降级不抛错」
- 顺手修好 `docs/ROUTES.md` 漂移

### 为什么便宜又值钱

排查真机问题时，「你说的是哪个版本」从**猜**变成**查**：
- `commit` 定位代码
- `presetHash` 定位**实际加载的那份 preset**（正是 v0.4.35 修掉的那类静默故障）
