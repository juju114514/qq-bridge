# 角色卡的出处与版权

本目录里的角色卡是**同人创作**，用来演示「人格卡怎么写」。先说清三件事：

1. **角色、名称、设定、形象的权利归原作者/权利方**，不归本项目；
2. 本项目的 MIT 许可**只覆盖本仓库的代码**，不覆盖这些角色与设定（见 [LICENSE](../LICENSE) 与 [NOTICE.md](../NOTICE.md)）；
3. 卡片**仅作个人自用/学习示例**，不用于商业用途，也不代表官方。

> 如果你是权利人，不希望某个角色出现在这里：开 issue 说明即可，会**立刻删除**，不需要走任何流程。

## 二、新增角色卡时请照这个来

在文件**开头的引用块里**写一行归属，格式：

```markdown
> ⚖ 同人设定·非官方；角色与设定版权归 <权利方>；仓库 MIT 只覆盖代码（详见 roles/ATTRIBUTION.md）
```

然后在本文件的表格里补一行。**没有归属行的卡片不要提 PR** —— 少一行归属，等于让项目替使用者背 IP 风险。

## 三、为什么要写在这里、而不是塞进人格卡正文

人格卡会被**每轮注入**到模型上下文里。归属声明只需要"存在且可查"，不需要占用每轮的 token，更不希望模型把它当成人设的一部分念出来（真踩过：把元信息写进正文后，模型会在对话里自我介绍"本卡为同人设定"）。

所以：**正文只留一行指针，详细说明放本文件**。
