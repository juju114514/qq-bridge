# 新功能：直播系统 + 刷抖音（v1.0）

> 2026-11-13 · 本次新增，不影响原有书房 / L2D / 记忆 / QQ 机器人功能

## 一、新增页面

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 直播画面 | `http://127.0.0.1:8796/stream.html` | OBS 浏览器源：星空背景 + 角色 + 字幕 + 弹幕 + 当前曲目 |
| 直播中控 | `http://127.0.0.1:8796/console-stream.html` | 语音、音乐、刷抖音、抖音直播四个区 |

## 二、直播中控的四块

### 1. 语音

```
输入一句 → 念出来 + 上字幕 + 画面冒气泡
快捷：进场欢迎 / 礼物感谢 / 房管点歌
接口：POST /stream/say {text}
```

### 2. 背景音乐（含闪避）

```
播放 / 暂停 / 上一首 / 下一首 · 顺序 / 随机 / 循环 · 歌曲音量
歌单目录：room-pet/music（mp3 / m4a / ogg / wav / flac）
闪避：她开口 0.3 秒压到 25%，说完 0.8 秒缓回 100%
  music.volume = 基准音量 × (1 - duck × 0.75)，duck 上升快、回落慢
```

### 3. 刷抖音（只读，NEW）

```
中控页填页数 → 开始刷 → 结果按赞数排序（标题直达 /video/<id>）
分享给管理员 → 生成文案并复制到剪贴板
可选：带评论（命令行 python douyin_browse.py --pages 2 --comments 5）
不点赞、不评论、不私信 —— 全只读
```

### 4. 抖音直播弹幕（NEW）

```
填直播间地址 → 开始监听（服务端拉起 live_douyin.py）
读页面 .webcast-chatroom___item 文本，1.2 秒一轮，去重后喂给中控
三个自动反应开关：进场欢迎 / 礼物感谢 / 朗读弹幕（同类 8 秒限流，队列最多 6 条）
```

## 三、新增接口

```
POST /stream/cmd            {playing, volume, mode}        音乐状态
GET  /stream/state                                         读状态 + 歌单
POST /stream/say            {text}                         让她说一句
GET  /music/list · /music/file?name=                       歌单
POST /live/msg              {user, text, kind}             喂一条弹幕（测试/外部接入）
GET  /live/recent           ?limit=50                      最近弹幕
GET  /live/watch/start      ?url=...                       启动直播间监听
GET  /live/watch/stop · /live/watch/status                 停止 / 状态
GET  /douyin/run            ?pages=2&comments=0            刷一轮
GET  /douyin/status · /douyin/latest · /douyin/digest      状态 / 结果 / 分享文案
```

## 五、使用前提

```
房间服务 8796 必须开着（这些页面都由它提供）
刷抖音 / 直播弹幕会各开一个独立配置的 Edge（<DY_PROFILE 目录>\browseprofile、liveprofile）
首次用某个配置时，在那个窗口里扫码登录一次，之后记住
OBS 浏览器源参数加 --autoplay-policy=no-user-gesture-required（否则音乐被自动播放策略拦截）
```

## 六、已知限制

```
· 抖音页面改版 → 选择器要跟着改（live_douyin.py 的 JS_COLLECT、douyin_browse.py 的 JS_CARDS）
· 刷抖音目前不带评论（要带得命令行加 --comments）
· 私信没做（写操作，需要你先同意再开）
· 弹幕密度取决于房间本身，冷清房间几十秒才一条
```
